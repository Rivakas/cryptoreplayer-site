CryptoReplayer – User guide

LTENRU

Application version 0.1.0 · guide updated 2026-10-11

CryptoReplayer replays historical cryptocurrency trades and simulates trading on them. It plays back the real trade flow of Bybit and Deribit on your computer and lets you trade in it as if the market were live: with fees, funding payments, slippage, latency, leverage, liquidation, options and multi-leg option strategies. All market data is free; no account and no API keys are needed.

Important. This is a tool for learning and for researching strategies. No orders are ever sent to an exchange; you trade with virtual money only. Simulated results do not guarantee the same results in the real market and are not investment advice.

1. Requirements and start-up

Microsoft Store version

Install CryptoReplayer from the Microsoft Store and start it from the Start menu. Nothing else needs to be installed – Node.js and the browser engine are inside the app. Windows 10 (2004) or later, 64-bit, is required.

  • The data cache, recorded quotes and a technical log (logs\server.log) are kept in the app's data folder, which Windows removes when the app is uninstalled.
  • The app uses local port 47821 (or the next free one); it is reachable only from your computer.
  • Zoom with Ctrl++ / Ctrl+− / Ctrl+0, full screen with F11.

Running from source

  • Operating system: Windows 10 / 11 (launchers start.vbs and stop.vbs). The server also runs on macOS or Linux with node server.js.
  • Node.js 22.15 or newer (nodejs.org). The first time, run npm install in the application folder.
  • Browser: a current Chrome, Edge or Firefox.
  • Internet connection to download historical data. Days already downloaded load from disk.

Starting on Windows

  1. Double-click start.vbs. The server starts in the background without a console window and the browser opens http://127.0.0.1:8787. If the server is already running, only the browser opens.
  2. stop.vbs stops the server (only the one from this folder). The log is written to server.log.

Manually: run node server.js, then open http://127.0.0.1:8787 in the browser. The server listens on the local computer only.

Settings via environment variables or .env

In a .env file in the application folder (see .env.example) or as environment variables:

Data cache

Each downloaded day is saved as data/<exchange>/<type>/<symbol>/<date>.crt.gz and loads in a fraction of a second next time. The cache can be deleted at any time – the data will be downloaded again when needed.

2. Quick start

  1. In the top bar choose the Exchange (e.g. Bybit), Type (Linear) and Instrument (e.g. BTCUSDT).
  2. Set Trade from (UTC) – the day you want to trade from – and the number of Days. To see earlier history, set an earlier date in Warm-up from (UTC).
  3. Click Load. The first time the day is downloaded (the status line shows the progress); later it loads from the cache.
  4. Click ▶ or press Space. Change the pace in Speed.
  5. In the Order panel on the right enter a quantity and click Buy / Long or Sell / Short (or press B / S).
  6. Follow the position, PnL and account in the Account panel and the Positions tab; close with Close or X.
  7. Review the results in the Trades, Fills and Equity curve tabs; save them with Export CSV.
  8. Not sure what a field or column means? Press F1 and hover over it to see an explanation.

Exchanges and contract types

ExchangeTypeWhat it is

Fields

  • Instrument – click to see the whole list; type to filter it. Only instruments with free data are listed. Once chosen, the status line shows the date range of the data.
  • expired (Deribit) – include futures that have already expired.
  • Warm-up from (UTC) – how far back the chart shows history before trading. It comes from the exchange kline APIs and is only drawn – you cannot trade in it. Higher intervals automatically get at least ~200 candles, but never more than one year back.
  • Trade from (UTC) and Days (1–14) – the period you replay with real trades.

Load downloads the trades, the funding history, the warm-up candles, the Bybit order book (if available) and option data (if the instrument has options). The account is reset and the replay starts from the first trade.

Data availability. Bybit publishes a day's file the next day around 01:00 UTC, so there is no Bybit data for today. Deribit allows today's (incomplete) data as well – it is not cached. All dates are UTC days.

5. Replay controls

  • ▶ / ⏸ (Space) – play / pause.
  • ⏭ (→) – to the end of the current candle; the step is the smallest interval of the visible charts.
  • ⏮ – back to the start of the period (the account is reset).
  • Speed – from 1× to 10000× real time; 60× means one minute per second.
  • Timeline – drag forward to fast-forward (orders fill on the way) or back (the account is reset after you confirm).
  • The clock shows the current replay moment. Everything – charts, prices, PnL – is shown only up to this moment.
  • Time – the time zone for all displayed times: UTC, Vilnius, London, Berlin, New York, Singapore, Tokyo or your computer's zone. Daylight saving time switches automatically. The date fields and the CSV export stay in UTC.

6. Charts

  • Charts: 2 side by side – two charts (by default 1D on the left and 15 min on the right); 1 – only the right one. Both are synchronised: the same replay time, positions, orders and drawings.
  • Interval (in the corner of each chart): 1s, 5s, 15s, 1m, 5m, 15m, 1h, 4h, 1D. Candles are rebuilt from the trades; nothing is lost.
  • Legend – O (open), H (high), L (low), C (close) and the change; hovering shows that candle.
  • Zoom: mouse wheel on the chart – time zoom; wheel over the price axis – price zoom; wheel over the time axis – time zoom around the cursor; the axes can be dragged. Auto or a double-click on the price axis restores automatic scaling, ⤢ shows the whole period, Log switches the logarithmic scale (on by default).
  • Marks on the chart: arrows – your fills; solid line – the position entry (long green, short red); orange dotted – the liquidation price; dashed – resting orders (TP orange, SL violet, with the expected PnL). Options are drawn as strike, break-even, TP and SL lines (see Options).
  • Day separators – blue dotted vertical lines at the start of each day in the selected time zone (can be turned off in the settings).
  • Clicking the chart (with no drawing tool active) puts that price into the Limit field (switching a market order to Limit) or into the Stop field.

7. Drawing tools

In the transport bar under Draw: ╱ trend line and ↗ ray (two clicks), ― horizontal and │ vertical line (one click), colour, line style (solid, dashed, dotted), width (1–4 px), 🔒 lock, ⌫ eraser and 🗑 delete all.

  • Lines are stored by time and price, so they appear on both charts; they are remembered per instrument in this browser.
  • With no tool active: click a line to select it; drag it to move it; drag an end handle to move that end; Ctrl + drag drags a copy (the original stays); Delete removes it; L or 🔒 locks / unlocks it.
  • Shift while placing the second point or dragging an end makes the line exactly horizontal. Trend lines and rays show their on-screen angle at the start.
  • A locked line cannot be moved or deleted (not even with the eraser or "delete all"). Esc cancels the tool or the selection.

8. Trading

Order form

  • Market – fills immediately (taker fee). Limit – waits for the given or a better price (maker fee). Stop – becomes a market order when the trigger price is reached.
  • Quantity – in instrument units: linear and spot – the base coin, inverse – USD contracts. Rounded to the allowed step. The 10 % / 25 % / 50 % / 100 % buttons fill it from the free margin and leverage.
  • Take profit / Stop loss – when the order fills, opposite reduce-only orders are placed automatically (TP – limit, SL – stop). They work as OCO: when one fills, the other is cancelled.
  • TP/SL units: Price – an absolute price; % – price move from the entry; $ P&L – profit / loss in dollars for the whole order. Enter positive numbers – the side follows Buy / Sell. The resulting prices and PnL are shown below the fields.
  • Reduce-only – the order can only reduce or close the position. Post-only (limit) – rejected if it would fill immediately.
  • Estimate – order value, margin, fee and the largest possible quantity.

Shortcuts: B – market buy, S – market sell, X – close the position at market.

TP/SL of an open position

In the Positions tab click TP/SL: a window opens where TP and SL are set as a price, % or $ from the entry, with a preview and a button to remove them. They cover the whole position and work as OCO; setting them again replaces the old ones.

9. How orders are filled

Neither Bybit nor Deribit offers free order book history, so orders are filled against the trade tape (the real historical trades):

  • Latency: an order becomes active only after the configured number of milliseconds.
  • Market and stop orders fill at the first trade after activation, at its price plus the configured slippage (bps). Where a Bybit order book exists (CryptoHFTData, since mid-2025), a market order walks the book levels and gets their average price.
  • Limit orders fill at their own price with the maker fee according to the chosen mode: through – a trade must happen at a better price than the limit (default, conservative); touch – a trade at the limit is enough (optimistic); queue – fills once the size that stood ahead of you in the book has traded (needs the order book).
  • If the limit price is already reached when the order is placed, it fills at once as a taker.
  • While the replay is paused, a market order fills immediately – the tape is advanced to the next trade.

10. Account, margin and fees

TypeQuantityPnL, fees, margin
Linearbase coinquote currency (USDT/USDC)
InverseUSD contractscoins; PnL = qty · (1/entry − 1/exit), the entry price is a harmonic mean
Spotbase coinlike linear, but with 1× leverage and no shorts; sells are always reduce-only, no funding
  • Fee = order value × rate. Maker – resting limit orders; taker – market and stop orders, limit orders that fill at once, and liquidations. Rates are set when an instrument is loaded: Deribit – from the API, Bybit – VIP0 (linear / inverse 0.02 % / 0.055 %, spot 0.1 % / 0.1 %). You can enter your own rates in the settings.
  • Funding (perpetuals) – a positive rate means longs pay shorts. Payment = position value at the last price × rate. Bybit – at the exchange's funding times, Deribit – every hour (interest_1h).
  • Margin = position value / leverage. Liquidation: when equity falls to the maintenance margin (position value × MMR, plus the maintenance margin of options), all orders are cancelled, the position is closed at market with the taker fee and options at their mark price.
  • The mark price for PnL and liquidation is the last trade price.

Account panel

Equity (wallet + unrealized PnL + option value), Wallet, Free margin, Realized PnL, Fees, Funding, Net PnL (and %), Max drawdown, Trades / won, Profit factor, Volume, Liquidations; with options also Option value, Option IM and Delta. Below – the parameters in use. Reset restores the starting balance and clears the history.

12. Options

The option chain appears after loading one of these instruments. In all three cases prices and IV come from Deribit option trades – the only free option history.

Chain

  • The Option chain view shows every strike live at the replay moment for the chosen expiry: position, last real trade, delta, IV, Bid and Ask (calls on the left, puts on the right).
  • The mark price comes from the Black-76 model and an IV smile built from the latest Deribit mark IVs; the forward is derived from Deribit prices. Italic IV means there have been no trades for this expiry yet and the IV is taken from the nearest expiry.
  • Bid / Ask are synthetic: mark ± spread (1.5 % by default, see the settings), because there is no historical option book. If real quotes were recorded for that day (see recording), those are used.
  • Blue background – ITM; the orange line – at the forward price. The header shows the index, forward, time left, ATM IV and the spread.

Trading options

  • Click Ask (buy) or Bid (sell) – the option form opens on the right. A market order fills at once (buy at the Ask, sell at the Bid); a limit order fills when the synthetic price reaches your price.
  • Short option margin (Deribit standard): initial – max(0.15 − OTM/S, 0.1) + mark, maintenance – 0.075 + mark (per contract, as a share of the index).
  • Settlement – on the expiry day at 08:00 UTC at the index; delivery fee min(0.015 % of the quantity, 12.5 % of the intrinsic value).
  • Option TP/SL – option price levels; they trigger on the mark price and close the whole position with a market order. Units: price, % of the premium or $.
  • Chart lines (as in ChromOptions): a strike line from opening to expiry (call green, put red; bought – solid, sold – dashed), a white break-even line, TP (orange) and SL (violet) at the approximate underlying price.
  • Max / Min – extremes of the option mark while the position is open and further until expiry (checked every ≤ 60 s of replay time).
  • Perpetuals and options share one account, so you can hedge; the portfolio delta is shown. Options are not available on a spot account.

13. Strategy builder

In the chain click 🧩 Strategy builder. Templates: vertical spread, butterfly, iron condor, riskless butterfly, riskless iron condor, collar / conversion, box spread. Choose the variant, expiry, strikes and quantity.

  • You see each leg (buy at the Ask, sell at the Bid, USD value, fee), the payoff diagram at expiry and the metrics: premium, fees, worst and best P&L (with delivery fees), break-even, approximate capital, ROI and APR.
  • The hedge leg U is the loaded instrument (perp / futures); its funding and basis are not included.
  • Open strategy opens all legs at market; if one fails, the legs already opened are closed again. The strategy appears in the Strategies tab.
  • The window does not block the replay: prices refresh every second; drag the window by its title, resize it and close it with Esc.

14. Scanner

🔍 Scanner tries every template at the current replay moment over the ~40 strikes nearest to the forward (up to 8 expiries) and ranks them by the APR of the worst-case result (up to 150 results shown). Filters: strategy, expiry, max. days to expiry, min. APR, "Riskless only" (worst ≥ 0), "Hide model arbitrage", "Refresh during replay" (every ~3 s). In builder opens a structure in the builder.

Without recorded quotes Bid/Ask are synthetic, so "riskless" and box results are mostly artefacts of the model. ⚠ marks structures whose prices break static arbitrage bounds; ✓ marks structures whose legs all have real recorded quotes.

15. Option quote recording

In the settings, under Option quote recording, click Turn on. While the server runs (in the Store version – while the app is open), every 5 min (see CR_RECORD_INTERVAL) it records the real Bid / Ask, sizes, mark and IV of Bybit (BTC, ETH) and Deribit (BTC, ETH, USDC) options to data/recorder (~20 MB per day). The state is kept across server restarts. Later the replay of those days uses the real Bid / Ask (the latest snapshot, if it is at most two intervals old, or 10 min for short intervals), and the chain header shows "real Bid/Ask (recorded)".

19. Data sources and limitations

DataSource
Bybit tradespublic.bybit.com daily (earlier – monthly) CSV files
Bybit instruments, funding, candlesapi.bybit.com (v5 API)
Bybit order bookapi.cryptohftdata.com (Bybit linear and spot, since mid-2025)
Deribit trades, instruments, optionshistory.deribit.com and www.deribit.com
Deribit funding and candleswww.deribit.com
  • There is no historical order book (except Bybit from CryptoHFTData), so fills are modelled from the trade tape; in the real market your order might have filled differently or not at all.
  • Your orders do not affect the historical price.
  • Without recordings, option Bid / Ask are synthetic and the mark price comes from a model.
  • Bybit rates are VIP0, because your own rates cannot be read without an API key.
  • Margin and liquidation are simplified (one position per account, mark = last price, no risk-limit tiers).
  • Exchange APIs can be temporarily unavailable or rate-limited – the application retries.

20. Privacy

  • The application runs on your computer. No account is needed, no personal data is collected, and no telemetry or statistics are sent to the developer.
  • The local server contacts only the public addresses of the exchanges and data providers (see section 19) to download market data. Nothing about you is sent to them apart from an ordinary network request (your IP address).
  • The TradingView Lightweight Charts™ library is installed with the app – no application files are loaded from the internet.
  • The browser's local storage (localStorage) holds only conveniences: the language, your last selection, simulation settings, drawings, window positions and sizes. Clear this site's data in the browser to remove them.
  • The market data cache and recorded quotes are stored in the data folder (or CR_DATA_DIR; in the Store version – in the app's data folder).

21. Troubleshooting and FAQ

"Server unreachable"

In the Store version close and reopen the app. When running from source, run start.vbs (or node server.js) and reload the page. If the server does not start, see server.log: the usual causes are an outdated Node.js or another program using port 8787 (change PORT).

"Bybit has not published the … file yet"

A Bybit day file appears the next day around 01:00 UTC. Choose an earlier date or wait.

The first load is slow

A day is downloaded and compressed once (tens of MB for BTCUSDT). Next time it loads from the cache in a fraction of a second. Deribit trades are downloaded page by page and can take longer.

No order book

The book exists only for Bybit linear and spot instruments since mid-2025. Elsewhere orders fill against the trade tape.

No option chain

The chain appears only after loading a Deribit BTC/ETH inverse, Deribit USDC linear or Bybit BTCUSDT / ETHUSDT instrument. If there are no prices yet, start the replay – IV appears after the first option trades.

The chart scale is "stuck"

Click Auto or double-click the price axis; ⤢ shows the whole period.

My drawings are gone

Drawings are saved per instrument and only in this browser. Load the same instrument on the same exchange.

How do I restore all default settings?

Store version: Windows Settings → Apps → Installed apps → CryptoReplayer → Advanced options → Reset (this also deletes the data cache). From source: clear the data of the site 127.0.0.1:8787 in the browser – the cache in the data folder stays.

Does the application trade with real money?

No. It does not connect to your exchange accounts and never sends any orders.
